## 📂 Projects

### 🎯 1. CareerIQ – Student Placement Prediction & Career Recommendation

CareerIQ is an intelligent career guidance system developed using **R Programming and R Shiny**.

It helps students understand their placement readiness and make better career decisions.

**Key Features:**
- Student placement probability prediction
- AI-based career recommendations
- Skill gap analysis
- Personalized career improvement plans
- Interactive analytics dashboard
- What-If Simulator and career goal planning

**Technologies:** R, R Shiny, Machine Learning, Random Forest, Logistic Regression, ggplot2

📁 **Project Folder:** [CareerIQ](./CareerIQ)

**How to Run:**
```bash
source("install_packages.R")
shiny::runApp()
```
Run these commands from inside the `CareerIQ` folder using R or RStudio.

### 🏥 2. HavNav – Indoor Hospital Navigation System

HavNav is a web-based indoor hospital navigation system designed to help patients and visitors easily navigate hospital buildings.

It provides digital navigation, room discovery, and hospital directory services.

**Key Features:**
- Indoor hospital navigation
- Room and department location assistance
- Shortest-path navigation using A* algorithm
- Interactive navigation interface
- Hospital directory and location management
- Modular and scalable application architecture

**Technologies:** React, TanStack Start, TypeScript, Node.js, A* Pathfinding Algorithm

📁 **Project Folder:** [HavNav](./HavNav)

**How to Run:**
```bash
npm install
npm run dev
```
Run these commands from inside the `HavNav` folder.
